下載資料

全部公開資料，提供 CSV（可用 Excel 開啟）、JSON，以及包含所有表格的 SQLite 檔。年份採天文紀年：0 即前1年。人物以永久編號（P0001）識別，編號永不改變。

全部表格（SQLite）
  • people 174 行

    每人一行。`merged_into` 為合併後記錄的編號。

    CSV JSON
  • names 598 行

    各人的其他名稱（字、號、諡、從祀稱號等）。

    CSV JSON
  • biographies 649 行

    各書所載人物傳記的位置。`copy` 與 `seq_start` 指向書頁掃描。

    CSV JSON
  • actions 0 行

    有日期的從祀行動。同一事件的不同記載共用 `occurrence`；`preferred` 標示所採用者。

    JSON
  • tenures 0 行

    由所採用的行動計算而得。`end_year` 為罷祀之年（空白即仍在祀）。

    JSON
  • proposals 0 行

    請祀某人的奏請及其結果（獲准、未准、擱置、未知）。

    JSON
  • relations 0 行

    人物之間的關係（師事、私淑、講友、父子）。

    JSON
  • polities 4 行

    收錄其廟學與祀典的國家。

    CSV JSON
  • ritual_systems 0 行

    全國性的祀典制度。

    JSON
  • temples 227 行

    實際的廟宇。年份採天文紀年（0 即前1年）。

    CSV JSON
  • documents 0 行

    詔令、奏疏與禮文（僅題名與出處）。

    JSON
  • sources 16 行

    資料所據的書籍與掃描本。

    CSV JSON
  • citations 1422 行

    其他表中某行的依據：`table` 與 `row_id` 指明是哪一行。

    CSV JSON
  • works 12 行

    祭孔文獻：每個版本一行。

    CSV JSON
  • work_sections 0 行

    各書的組成部分及其內容（內容類型代碼，以逗號分隔）。

    JSON
  • hymns 0 行

    祭祀樂章，每一儀節、每一制度各一行。

    JSON
  • scores 0 行

    樂譜與舞譜：哪一書的哪一部分，以何種記譜法譜寫哪一樂章。

    JSON
  • roster_entries 174 行

    位次表中的各位，依原書所載。

    CSV JSON
