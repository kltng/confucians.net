Download the data

All public data, as CSV (opens in Excel), JSON, or one SQLite file with every table. Years are astronomical: 0 is 1 BCE. People are identified by their permanent ID (P0001), which never changes.

All tables (SQLite)
  • people 174 rows

    One row per person. `merged_into` gives the ID of the record a merged person now lives in.

    CSV JSON
  • names 598 rows

    Other names of each person (字, 號, 諡, 從祀稱號 …).

    CSV JSON
  • biographies 649 rows

    Where each book gives a person's biography. `copy` and `seq_start` locate the page scan.

    CSV JSON
  • actions 0 rows

    Dated enshrinement actions. Accounts of one event share an `occurrence`; `preferred` marks the one used.

    JSON
  • tenures 0 rows

    Computed from the preferred actions. `end_year` is the year of removal (empty = still there).

    JSON
  • proposals 0 rows

    Requests to enshrine someone, with the outcome (approved, rejected, shelved, unknown).

    JSON
  • relations 0 rows

    Person-to-person links (師事, 私淑, 講友, 父子).

    JSON
  • polities 4 rows

    States whose temples and rules are recorded.

    CSV JSON
  • ritual_systems 0 rows

    Empire-wide or kingdom-wide sacrificial rules.

    JSON
  • temples 227 rows

    Real temples. Years are astronomical (0 = 1 BCE).

    CSV JSON
  • documents 0 rows

    Edicts, memorials and ritual texts (title and locator only).

    JSON
  • sources 16 rows

    Books and scans that facts are cited from.

    CSV JSON
  • citations 1422 rows

    Evidence for a row in another table: `table` and `row_id` say which one.

    CSV JSON
  • works 12 rows

    The 祭孔文獻 corpus: one row per edition.

    CSV JSON
  • work_sections 0 rows

    Parts of each work and what they contain (content-kind codes, separated by commas).

    JSON
  • hymns 0 rows

    Hymns of the sacrifice, one per ritual step and rule.

    JSON
  • scores 0 rows

    Music and dance scores: which book section sets which hymn, in which notation.

    JSON
  • roster_entries 174 rows

    Seats in rosters, as the book gives them.

    CSV JSON
